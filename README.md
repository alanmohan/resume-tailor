# Resume Tailor

- Live app: <https://resume-tailor-web-saj1.onrender.com>
- API: <https://resume-tailor-api-ax8j.onrender.com> (`/healthz`, `/readyz`)

## What the project does

This application allows users to generate a tailored resumes and cover letter for a job posting, based on their existing resume, LinkedIn profile, and any other relevant sources. It extracts the user's profile information and generates a tailored resume and cover letter that highlights the user's qualifications for the specific job, grounded in the source documents. For each generated component, the corresponding source information is provided so the user can verify the accuracy of the generated content.

## How to use it

Users simply need to copy and paste their resume, LinkedIn profile, and any other relevant information relevant to their job search into the application.
Then, they can paste the job description of the position they are applying for. The application will generate the resume and cover letter fr the provided job decription.

## Features I am most proud of

- RAG architecture that grounds the generated documents in the user's source documents and shows the source of each claim.
- A modern react frontend with a clean UI
- A NoSQL database in MongoDB that stores the user's profile, embeddings, and generated documents.

## Running it locally

You need Python 3.12, Node.js, and Docker (for the database). Open three terminals, in the project folder.

**1. Set up your settings and start the database**

```bash
test -f .env || cp .env.example .env
docker compose up -d mongo
```

Open the new `.env` file and put your OpenAI key in `OPENAI_API_KEY`. If you just want to try the app for free without a key, set `AI_PROVIDER=fake` instead. The app then runs in a clearly labelled demo mode with pretend AI answers.

**2. Start the backend (terminal 1)**

```bash
cd backend
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt -r requirements-dev.txt
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

To check it works, open <http://127.0.0.1:8000/healthz> in your browser.

**3. Start the frontend (terminal 2)**

```bash
cd frontend
npm ci
cp .env.example .env.local
npm run dev -- --host 127.0.0.1
```

**4. Use the app**

Open <http://127.0.0.1:5173> in your browser. Paste your resume, then a job description, and generate your documents (or click "Try sample profile").

When you are done, press `Ctrl+C` in each terminal and run `docker compose stop mongo` to stop the database.

## How secrets are handled

Secrets are stored in environment variables, which have not been comitted. The frontend and backend each have their own `.env` file which is gitignored. The example `.env` files are provided in the root of the repository, and the user can copy them to create their own `.env` files with their own secrets.
